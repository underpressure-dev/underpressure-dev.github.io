Datenschutzerklärung

Verantwortlicher

Michael Küng, Industrietaucher.ch, Luzern, Schweiz. Kontakt: info@underpressure.ch. Es gilt das Schweizer Datenschutzgesetz (DSG).

Was diese Website tut und nicht tut

  • Sie setzt keine Cookies und verwendet keine Tracking- oder Analysewerkzeuge.
  • Sie bindet keine externen Dienste ein. Schriften, Bilder und Skripte werden von dieser Website selbst ausgeliefert. Einzige Ausnahme ist der Sicherheitscheck, und nur wenn Sie ihn benutzen.
  • Der Projektbrief auf der Kontaktseite sendet nichts. Er öffnet nur Ihr eigenes E-Mail-Programm mit einem vorbereiteten Text.
  • Die Demos speichern Ihre Eingaben ausschliesslich im lokalen Speicher Ihres Browsers. Sie werden nicht an einen Server gesendet. Der CAD-Viewer liest Ihre Dateien nur in Ihrem Browser.

Sicherheitscheck

Wenn Sie im Sicherheitscheck eine Domain prüfen, sendet Ihr Browser diese Domain an einen Prüfdienst. Er läuft auf der Plattform von Cloudflare, Inc. (USA) und wird von der Alta Engineering AG, Weggis, betrieben, mit der wir dafür zusammenarbeiten. Der Prüfdienst ruft die öffentliche Startseite, die Datei security.txt und öffentliche DNS-Einträge dieser Domain ab, die DNS-Einträge über den Namensdienst von Cloudflare, und schickt das Ergebnis an Ihren Browser zurück. Er speichert weder die Domain noch das Ergebnis. Damit er nicht für Massenabfragen missbraucht wird, zählt er die Prüfungen pro Absender während einer Stunde. Dafür verwendet er einen Hashwert Ihrer IP-Adresse, nicht die Adresse selbst. Bitte prüfen Sie nur Domains, für die Sie verantwortlich sind oder die Sie prüfen dürfen.

Zeichnung zu Offerte

Wenn Sie im Werkzeug «Zeichnung zu Offerte» eine Datei hochladen, sendet Ihr Browser diese Datei an unseren eigenen Werkzeug-Server. Dort wird sie an ein Sprachmodell von Anthropic, PBC (USA) übergeben, das die Zeichnung liest. Die Datei und das Ergebnis werden weder auf unserem Server noch von Anthropic für ein Training gespeichert. Laden Sie keine Unterlagen hoch, die Sie nicht weitergeben dürfen.

Angriffsfläche

Wenn Sie im Werkzeug «Angriffsfläche» eine Domain eingeben, fragt unser Werkzeug-Server öffentliche Quellen zu dieser Domain ab: Certificate Transparency (über crt.sh) und DNS (über den Namensdienst von Cloudflare). Es werden keine Angriffe und keine Scans ausgeführt. Weder die Domain noch das Ergebnis werden gespeichert. Gegen Massenabfragen zählt der Server die Abfragen pro Absender während einer Stunde, dafür verwendet er einen Hashwert der IP-Adresse, nicht die Adresse selbst. Die Liste der Hostnamen wird erst nach einem DNS-Nachweis der Domain angezeigt.

Technische Daten beim Aufruf

Die Website wird über GitHub Pages ausgeliefert. Beim Aufruf verarbeitet der Hosting-Anbieter technisch bedingt Angaben wie die IP-Adresse und die aufgerufene Seite, zum Beispiel in Server-Protokollen. Anbieter ist GitHub, Inc., ein Unternehmen von Microsoft, mit Sitz in den USA. Wir haben darauf keinen Einfluss und werten diese Daten nicht aus.

Kontaktaufnahme

Wenn Sie uns schreiben oder anrufen, verwenden wir Ihre Angaben nur, um Ihre Anfrage zu beantworten. Wir geben sie nicht an Dritte weiter, ausser es ist für die Bearbeitung nötig oder gesetzlich vorgeschrieben. Unsere E-Mails laufen über Google Workspace der Google Ireland Limited. Dabei können Daten auch in den USA bearbeitet werden. Google bearbeitet sie in unserem Auftrag und auf der Grundlage von Standardvertragsklauseln.

Ihre Rechte
