Software

Software that works for your business.

We develop websites and applications for companies, with experience going back to 2015. We write the code ourselves and deliver every solution with a manual, with no follow-up costs.

01

What we build

Most businesses do not need a huge platform. They need a tool that maps exactly their process, that everyone understands right away and that still runs in five years.

That is exactly what we build. We listen first: how do you work today, where is time lost, where do errors happen? Then we design the simplest solution that really solves the problem. That can be a fast website, a client portal, a time tracking tool or a small controller that monitors a machine.

You work directly with development. We write the code ourselves, use AI as a tool and document everything so that you do not depend on us.

Five areas, one way of working

Choose an area. For each one you see typical tasks, how we go about it and what you end up with.

Websites

A website is a company's first impression and works around the clock. We build it to load fast, work on every device and be legally sound.

Typical tasks

  • Company site, business card or product page
  • Multilingual, for example German and English
  • Imprint and privacy policy under Swiss law
  • Search engine basics and structured data

How we build it

We write the pages by hand, without a heavy site builder. Fonts and images live on your server, not at Google. Without tracking there is no need for a cookie banner. We check every page on a phone and a desktop, in light and dark mode.

What you get

A fast, accessible website that you can maintain yourself or that we adapt for you. We also set up the domain, email forwarding and search engine listing.

  • HTML
  • CSS
  • JavaScript
  • GitHub Pages
  • Schema.org
  • DNS

Web apps and portals

When clients exchange files, staff sign in or data needs to be managed cleanly, you need an application rather than a website.

Typical tasks

  • Client portal with file exchange and sharing links
  • Sign-in, roles and access rights
  • Dashboards with key figures
  • Interfaces to existing systems

How we build it

The application runs in the browser, without installation. Sign-in goes through an upstream access service, and the server checks permissions on every request. Every important action is logged and data is backed up daily.

What you get

A tool your clients and your team understand right away, and a manual that describes how it is built and how to run it.

  • Cloudflare Workers
  • Cloudflare Access
  • Backblaze B2
  • Next.js
  • PostgreSQL

Business software

Time tracking, document control, expenses, holiday planning: off-the-shelf software costs licences and still never quite fits. We build the solution for your process.

Typical tasks

  • Time tracking with flextime, holidays and expenses
  • Document control with approval workflow and versions
  • Online manuals and audit reports
  • Exports in the format you already use today

How we build it

We start with your current process, for example the Excel list everyone knows. It becomes an application with a database that calculates, checks and reminds. In the end the export looks like what your bookkeeping already knows.

What you get

Less paperwork, fewer errors and figures that add up. The live demos on this site show what it looks like in practice.

  • Next.js
  • Prisma
  • PostgreSQL
  • Vercel
  • Excel-Export

Automation and AI

Many tasks repeat every day. We automate them and use AI where it really helps.

Typical tasks

  • Take over data from emails, PDFs or lists
  • Assistants for your own documents and processes
  • Create reports and analyses automatically
  • Connect processes between existing programs

How we build it

We use AI every day in development and know its strengths and limits. Before we build anything, we tell you honestly whether AI is the right solution or whether a simple script will do. Your data stays under your control.

What you get

Hours your team gets back every week, and a clear statement of what runs automatically and what a person checks.

  • Python
  • JavaScript
  • API
  • LLM

Hardware and controls

Sometimes software should not just show figures but move, measure or transmit something.

Typical tasks

  • Microcontrollers such as Arduino and Raspberry Pi Pico
  • Sensors, data logging and radio
  • CNC control and integration
  • Firmware for special applications

How we build it

We build electronics that have to work in harsh conditions: racing drones with custom firmware, balloon systems up to 38 km altitude. The mechanical side is part of it too, with CAD design based on training as a design engineer (Konstrukteur EFZ).

What you get

A prototype that works, with documented circuitry and software, so you can build on it.

  • Arduino
  • CircuitPython
  • Betaflight
  • ArduPilot
  • ExpressLRS
  • SolidWorks
  • Fusion 360
03

How a solution is structured

A typical application consists of a few clearly separated parts. The browser shows the interface. Access protection checks who you are. The application contains the rules of your business, calculates and writes a log. Data lives in a database, files in their own storage, and both are backed up every day.

This separation makes the solution robust and understandable. Each part can be checked, replaced or extended on its own. That is exactly how it is described in the manual.
