Client portal (demo)

File exchange with sharing links, expiry and password. Working demo with sample data.

Demo with made-up sample data. Everything you enter stays in your browser.

The demo requires JavaScript.

Manual: Client portal

Purpose

The client portal replaces email attachments: each client has a folder, files can be exchanged internally and externally, and individual files are shared via sharing links.

Usage

With "View as" you switch between internal (administration) and a client.

  • Internal: see all clients, upload and download files, create and revoke sharing links.
  • Client: sees only their own folder, uploads and downloads.
  • Sharing link: choose validity and optionally set a password. The link is the address of a page where the file is fetched.
  • Activity: every upload, download and share is logged.

Note on the demo

In the demo, uploaded files stay in memory for this session only. After reloading the file list is still there, the content of your own files is not.

Typical set-up of a real solution

Files live in object storage, sign-in runs through an upstream access service, sharing links are checked server-side. The manual describes backup and restore.
