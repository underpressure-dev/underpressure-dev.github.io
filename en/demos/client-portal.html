Client portal

One folder per client, uploads from both sides and sharing links with expiry and password.

Made-up sample data. Everything stays in your browser.

The demo requires JavaScript.

Manual: Client portal

Purpose

The client portal replaces email attachments: each client has a folder, both sides can exchange files, and individual files are shared via sharing links.

Usage

At the top right you switch between administration and a client.

  • Administration: all clients, upload and download files, create and revoke sharing links.
  • Client: sees only their own folder.
  • Upload: choose a file or drag it into the drop zone.
  • Sharing link: choose validity, optionally set a password. The recipient needs no account.
  • Activity: every upload, download and share is logged.

Note on the demo

In the demo, uploaded files stay in memory for this session only. After reloading the file is still listed, its content is not.

Real solution

Files live in object storage, sign-in runs through an upstream access service, the server checks sharing links. The manual describes backup and restore.
