Privacy policy

Controller

Michael Küng, Industrietaucher.ch, Lucerne, Switzerland. Contact: info@industrietaucher.ch. The Swiss Federal Act on Data Protection (FADP) applies.

What this website does and does not do

  • It sets no cookies and uses no tracking or analytics tools.
  • It embeds no external services. Fonts, images and scripts are served by this website itself. The only exception is the security check, and only if you use it.
  • The project brief on the contact page sends nothing. It only opens your own email program with a prepared text.
  • The demos store your input only in your browser's local storage. It is not sent to any server. The CAD viewer reads your files only in your browser.

Security check

When you check a domain in the security check, your browser sends this domain to a check service. It runs on the platform of Cloudflare, Inc. (USA) and is operated by Alta Engineering AG, Weggis, with whom we work together for this. The check service retrieves the public home page, the security.txt file and public DNS records of this domain, the DNS records via the Cloudflare name service, and sends the result back to your browser. It stores neither the domain nor the result. So that it cannot be misused for mass queries, it counts the checks per sender for one hour. For this it uses a hash value of your IP address, not the address itself. Please only check domains you are responsible for or are allowed to check.

Drawing to quote

When you upload a file in the «Drawing to quote» tool, your browser sends this file to our own tool server. There it is passed to a language model from Anthropic, PBC (USA), which reads the drawing. Neither our server nor Anthropic stores the file or the result for training. Do not upload documents you are not allowed to share.

Attack surface

When you enter a domain in the «Attack surface» tool, our tool server queries public sources about this domain: Certificate Transparency (via crt.sh) and DNS (via the Cloudflare name service). No attacks and no scans are carried out. Neither the domain nor the result is stored. Against mass queries the server counts queries per sender for one hour, using a hash value of the IP address, not the address itself. The list of hostnames is only shown after a DNS proof of the domain.

Technical data when you visit

The website is served via GitHub Pages. When you visit, the hosting provider processes technical data such as your IP address and the page requested, for example in server logs. The provider is GitHub, Inc., a Microsoft company based in the USA. We have no influence over this and do not evaluate this data.

Getting in touch

If you write to or call us, we use your details only to answer your request. We do not pass them on to third parties unless needed to handle the request or required by law.

Your rights

You can request information about your data and its correction or deletion. Write to the email address above.
